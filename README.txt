AI Interview Preparation System — Beginner VS Code Project

HOW TO RUN
1. Download and extract the ZIP file.
2. Open Visual Studio Code.
3. Click File > Open Folder and choose the extracted AI_Interview_Preparation_System_VSCode folder.
4. Open index.html.
5. Run it with the Live Server extension (right-click index.html > Open with Live Server).
   If Live Server is not installed, open index.html directly in your browser.

FILES
- index.html: page content
- style.css: layout and styling
- script.js: question bank, category switching, self-rating, and saved practice history

FEATURES
- HR & Personal, Web Development, and Python practice questions
- Answer tips
- Confidence rating from 1 to 5
- Save practice history in the current browser
- Progress summary

IMPORTANT
This is a beginner-friendly front-end prototype. It uses a prepared question bank; it does not call an AI service or automatically score answers. Saved history is stored in browser localStorage on this device. The answer text itself is not saved.
